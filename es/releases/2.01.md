# Release 2.01 (Diciembre 2025)

## Resumen
- Estandarización de cabeceras profesionales en JS/PHP con versión 2.01.
- Herramientas en `tools/` para generar e insertar cabeceras automáticamente.
- Hook `pre-commit` para aplicar cabeceras y elevar versión en todos los módulos.
- Limpieza de endpoints `test_*` no usados, manteniendo solo los referenciados.
- Escaneo global en `backend/modules/admin/*` y `backend/modules/user/*`.

## Cambios Clave
- Cabeceras
  - Actualización de `@version` a `2.01` en archivos JS del módulo BDV Portal.
  - Inserción automática de cabeceras completas donde faltaban en todo el proyecto.
- Herramientas
  - `tools/scan_headers.php`: escáner global para detectar y aplicar cabeceras (con `--apply` y `--bumpVersion`).
  - `tools/generar_cabecera.php`: generador de cabeceras parametrizable (JS/PHP).
  - `.git/hooks/pre-commit`: ejecuta el escáner antes de cada commit.
- Limpieza
  - Eliminación de endpoints `test_*` de `bdv_portal` no referenciados.
  - Conservación de `test_*` usados por `email`, `settings/mail_api`, `totp` y `dist/lite`.
- Configuración
  - Inclusión de `tools/` en `.gitignore` como herramientas locales de desarrollo.

## Comandos Útiles
```bash
# Aplicar cabeceras globalmente
php tools/scan_headers.php --apply --bumpVersion

# Generar cabecera específica (ejemplo JS)
php tools/generar_cabecera.php \
  --tipo=js \
  --nombre=tesoreria.js \
  --descripcion="Gestión de Tesorería BDV (saldo y movimientos)" \
  --subpackage="Backend/modulos/admin/bdv_portal/js/tesoreria.js" \
  --namespace="modAdminBdvTesoreria" \
  --version=2.01 \
  --since=2025-12-19
```
