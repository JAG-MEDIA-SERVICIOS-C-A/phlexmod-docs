# Política de Seguridad

Si descubre una vulnerabilidad en PHLEXMOD, por favor repórtela inmediatamente vía correo electrónico.

**Contacto**: security@jagmedia.com.ve

## Clave PGP
Nuestra clave pública se encuentra en: `/.well-known/gpg.asc`

## Alcance
Aceptamos reportes sobre:
- Vulnerabilidades XSS, CSRF, SQL Injection.
- Fallos en el control de acceso (MIA-C4I).
- Exposición de datos sensibles.

**NO reporte bugs públicos en GitHub Issues.**
